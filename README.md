# homebrew-siba

Homebrew tap for [SIBA](https://siba.az) tools.

```
brew tap aghasalim/siba
brew trust aghasalim/siba
brew install sibac
```

The `brew trust` line is for Homebrew 7 and newer; skip it on older versions.

`sibac` is SIBA Code, a coding agent for the terminal: https://github.com/aghasalim/sibac
